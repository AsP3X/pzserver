version=1
title=PZServerPulse
description=PZServerPulse is a server-side character dashboard mod. It exports live character data (health, skills, moodles, equipment, temperature, protection, encumbrance, wounds, recipes) as per-player JSON heartbeat files for the PZServer web dashboard.
description=
description=[h1]What it does[/h1]
description=[list]
description=[*]Exports live character health (overall + per body part) with wound tracking
description=[*]Exports all trained skills with XP progress percentages
description=[*]Exports moodles: hunger, thirst, fatigue, stress, panic, pain, and more
description=[*]Exports equipped weapon condition, sharpness, ammo, and attachments
description=[*]Exports worn clothing with condition, holes, and bite/scratch protection
description=[*]Exports body temperature (core + per-part skin/insulation)
description=[*]Exports encumbrance (current load vs. capacity)
description=[*]Exports quickload hotbar slots
description=[*]Exports open wounds with triage status (treated/untreated)
description=[*]Exports recently learned recipes
description=[*]Writes per-player JSON heartbeat files every ~10 real seconds
description=[/list]
description=
description=[h1]Important[/h1]
description=This mod does nothing on its own. It is one half of a pair: it writes JSON heartbeat files to the server's Lua/PZServerPulse/ directory, and the PZServer web dashboard reads them to display live character data. Installing it without the companion dashboard will have no visible effect in-game.
description=
description=It is intended for dedicated servers running the PZServer management stack. Communication is entirely file-based — there are no network calls, no telemetry, and nothing is sent anywhere by the mod itself.
description=
description=[h1]Setup[/h1]
description=Add the mod to your server, and set DoLuaChecksum=false in your server config so clients without a matching Lua checksum can still connect. The heartbeat files are written under the server's Lua/PZServerPulse/ folder.
description=
