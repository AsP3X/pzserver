title=Knox Relay
description=Knox Relay is a server-side bridge mod. It exposes live server data as JSON files on disk so an external management panel can read the server's state and send instructions back.
description=
description=[h1]What it does[/h1]
description=[list]
description=[*]Exports the in-game clock, season and weather
description=[*]Exports player positions for a live map
description=[*]Exports per-player inventory snapshots
description=[*]Exports player progression (kills, hours survived, profession, trained perks)
description=[*]Exports the full item catalogue, including items added by other mods
description=[*]Processes queued item deliveries and removals, with verified variants that roll back on failure
description=[*]Converts in-game cash into an external wallet balance, items-first so nobody is charged for a deposit that did not complete
description=[*]Optional respawn cooldown after death
description=[*]Optional PvP safe zones with violation logging
description=[*]Records player-versus-player kills
description=[/list]
description=
description=[h1]Important[/h1]
description=This mod does nothing on its own. It is one half of a pair: it writes and reads JSON files, and something outside the game has to act on them. Installing it without that companion software will have no visible effect in-game.
description=
description=It is intended for dedicated servers. Communication is entirely file-based - there are no network calls, no telemetry, and nothing is sent anywhere by the mod itself.
description=
description=[h1]Setup[/h1]
description=Add the mod to your server, and set DoLuaChecksum=false in your server config so clients without a matching Lua checksum can still connect. The bridge files are written under the server's Lua folder.
description=
